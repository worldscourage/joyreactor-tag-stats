# Прочти меня — быстрый старт

Проект собирает посты одного тега с joyreactor.cc за указанный период и считает
статистику по авторам: количество постов, а также **MIN / MAX / SUM** (и среднее)
их рейтинга.

Тег по умолчанию — `Бенефис кринжа`. Нужен **Python 3.10 или новее**.

---

## Шаг 1. Установить Python

**macOS**
```bash
brew install python@3.12
```

**Ubuntu / Debian**
```bash
sudo apt update && sudo apt install -y python3 python3-venv python3-pip
```

**Windows**
```powershell
winget install Python.Python.3.12
```
Или скачать установщик с [python.org](https://www.python.org/downloads/windows/) и
обязательно поставить галочку **«Add python.exe to PATH»**.

---

## Шаг 2. Зайти в папку проекта

Открыть терминал (на Windows — **PowerShell**) и перейти в распакованную папку:

```bash
cd путь/к/cringe-stats
```

---

## Шаг 3. Создать виртуальное окружение и установить проект

**macOS / Ubuntu**
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
```

**Windows (PowerShell)**
```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -e .
```

Если PowerShell отказывается запускать активацию, один раз разрешить это для
своего пользователя:
```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

---

## Шаг 4. Проверить, что всё работает

```bash
joy-stats --version
```

Если команда не найдена — использовать равнозначный вариант:
`python -m joyreactor_stats` (на Windows: `py -m joyreactor_stats`).

---

## Шаг 5. Запустить

Указать период — это единственное, что обязательно:

```bash
# Всё за август 2025 года
joy-stats --start 2025-08-01 --end 2025-09-01

# Последние 30 дней, с сохранением файлов в папку reports
joy-stats --last-days 30 --out-dir reports
```

В папке `reports` появятся файлы: `posts.csv` (посты), `authors.csv` (статистика по
авторам), `report.json` (всё вместе) и «чемпионы» — `champions.json`, `champions.txt` и
`champions-ru.txt` (на русском).

---

## Основные параметры

| Параметр | Что делает |
| --- | --- |
| `--start ДАТА` | С какой даты брать посты: `2025-08-01` или `"2025-08-01 12:30"`. |
| `--end ДАТА` | По какую дату включительно. По умолчанию — сейчас. |
| `--last-days N` | Вместо `--start`: последние N дней. |
| `--tag "ИМЯ"` | Другой тег. По умолчанию `Бенефис кринжа`. |
| `--url "АДРЕС"` | Ссылка на тег прямо из адресной строки браузера. |
| `--out-dir ПАПКА` | Куда сохранить `posts.csv`, `authors.csv`, `report.json`. |
| `--sort-authors-by КЛЮЧ` | Сортировка авторов: `score_sum` (по умолчанию), `score_max`, `score_min`, `score_avg`, `score_positive_sum`, `score_negative_sum`, `author_rating`, `posts`, `comments_sum`, `author`. |
| `--show-posts N` | Сколько постов вывести в консоль (по умолчанию 15, `0` — не выводить). |
| `--comment-stats` / `--no-comment-stats` | Собирать статистику по комментариям или нет. Если флаг не указан — программа спросит. |
| `--common-tag-share Ч` | Доля, выше которой тег считается общим и не попадает в заголовок (по умолчанию `0.5`, `1` — оставить все теги). |
| `--champions` / `--no-champions` | Создавать файлы «чемпионов» или нет (по умолчанию — да, нужен `--out-dir`). |
| `--delay СЕК` | Пауза между запросами к сайту (по умолчанию 0.5). |

Полный список: `joy-stats --help`.

## Другой тег

Проще всего скопировать ссылку из браузера — имя тега подставится само:

```bash
joy-stats --url "https://joyreactor.cc/tag/anon/all" --start 2025-01-01 --end 2025-02-01
```

Или задать имя тега напрямую:

```bash
joy-stats --tag "Бенефис кринжа" --start 2024-08-23 --end 2024-09-01
```

## Что означают колонки

- **Score / Min / Max / Sum / Avg** — рейтинг постов. Сайт считает его дробным, и он
  может быть отрицательным: `-14.92` значит, что пост заминусовали.
- **Comments** — количество комментариев.
- **Plus / Minus** (`score_positive_sum`, `score_negative_sum`) — отдельно сумма рейтинга
  плюсовых постов автора и отдельно сумма минусовых. Один только `score_sum` этого не
  показывает: у автора с постами `+100` и `-100` и у автора с двумя нулевыми постами сумма
  одинаковая — ноль. Пост с рейтингом ровно `0` не попадает ни в одну из колонок, поэтому
  `Plus + Minus` всегда равно `Sum`. Если постов одной из сторон нет, там `0.00` — без
  знака, потому что это «таких постов нет», а не «маленькая сумма».
- **Rating / Stars** (`author_rating`, `author_stars`) — рейтинг автора на сайте и число
  звёзд, которое ему соответствует. Звёзды считаются по тем же порогам, что и на сайте:
  20 рейтинга — первая звезда, 50 — вторая, 150 — третья и так далее. В профиле звёзды
  показаны рядами по десять, здесь это просто число: рейтинг 20 620 — это `14` звёзд.
  В консоли звёзды рисуются символами (`★★★★`), а после десяти — числом (`★×14`).
  Важно: это рейтинг **на момент сбора данных**, а не свойство поста; в таблице по авторам
  берётся значение из самого свежего поста автора за период. Лишних запросов не стоит —
  сайт отдаёт рейтинг вместе со списком постов.
- **Лучший / худший комментарий** — автор и рейтинг комментария с самым высоким и самым
  низким рейтингом в посте.
- **Самый обсуждаемый комментарий** — автор, число прямых ответов (`Direct`) и число
  ответов во всей ветке под ним, на любой глубине (`All`).
  Сбор этих данных стоит один запрос на каждый пост с комментариями — это самая долгая
  часть работы.

Поэтому, если флаг не указан, программа **спросит** перед этим этапом — уже после сбора
постов, когда известна настоящая цена:

```
23 of 34 collected posts have comments.
Reading their threads ... costs 23 requests, ~12 s.
Collect comment statistics? [Y/n]
```

Enter — согласиться, `n` — пропустить. Чтобы вопроса не было, укажите заранее
`--comment-stats` или `--no-comment-stats`. Это важно для скриптов и cron: если терминала
нет, программа не зависает, а пропускает этот этап и пишет предупреждение.
- **Title** — первая строка текста поста. Если текста нет (пост из одной картинки или
  видео), вместо заголовка подставляются теги поста. Теги, которые есть более чем у
  половины выбранных постов, при этом отбрасываются: они ничего не говорят о конкретном
  посте. Например, при выборке из 34 постов отбрасываются `Бенефис кринжа` и `приколы для
  полных дегенератов` (по 100%), а `видео` (ровно 17 из 34) остаётся — «ровно половина»
  это не «более половины». Порог меняется флагом `--common-tag-share`. Если после
  фильтрации тегов не осталось, выводится `(no text — image or video post)`.
- Время везде московское (UTC+03:00) — как на сайте.

## Чемпионы (champions)

После сбора данных программа сама выбирает самое заметное за период и пишет это в три
файла: `champions.json`, `champions.txt` (по-английски) и `champions-ru.txt` (по-русски).
Дополнительных запросов к сайту это **не стоит**. В каждой строке: автор, его звёзды и
рейтинг, рейтинг самого поста или комментария, ссылка прямо на него и заголовок (у
комментария заголовка нет — вместо него короткая цитата).

Разделы:

1. Топ-10 постов.
2. Худшие 10 постов.
3. Худший пост в каждой звёздной группе авторов ниже 10 звёзд (группы, которых в выборке
   нет, просто пропускаются).
4. 3 комментария с самым высоким рейтингом.
5. 3 комментария с самым низким рейтингом.
6. 3 комментария с наибольшим числом прямых ответов.
7. 3 комментария с самой большой веткой под ними (ответы на любой глубине).

Разделы 4–7 считаются **по всем постам сразу**, поэтому все три победителя вполне могут
оказаться в одном обсуждении. Для них нужен `--comment-stats`; без него в этих разделах
будет прямо написано, что данные не собирались.

Эти же файлы можно пересобрать позже из готового `report.json`, без обращения к сайту:

```bash
joy-champions reports/report.json
joy-champions reports/report.json --out-dir /tmp/champs
```

## Если что-то не так

- **`joy-stats: command not found`** — окружение не активировано. Повторить `source
  .venv/bin/activate` (Windows: `.\.venv\Scripts\Activate.ps1`) или запускать через
  `python -m joyreactor_stats`.
- **Кракозябры вместо русских букв в консоли Windows** — выполнить `chcp 65001` или
  использовать Windows Terminal.
- **Excel портит русские имена в CSV** — не должен: файлы сохраняются с BOM. Если всё
  равно портит, импортировать как UTF-8.
- **`Could not read the tag`** — проверить имя тега и доступность сайта; при нестабильной
  сети помогает увеличить паузу: `--delay 2`.
